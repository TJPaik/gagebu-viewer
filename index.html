선택 기간 내역

검색은 아래 목록에만 적용돼요. 합계와 차트는 조회 설정을 따릅니다.
페이지를 처음 열 때 과거 내역까지 자동 정산하고 사본을 고정해요. 시트 직접 수정은 브라우저 새로고침(F5) 후 반영돼요. 카드 사용 정산 저장 시에도 다음 달 카드대금에 반영해요. 미납부는 건너뛰며 중복·연결 오류는 알려드려요. 제외된 사용내역도 정산에 포함해요.
카드/통장 시트의 ‘카드대금 표기’에 내용 칸의 표기(예: OO카드)를 한 번 등록하세요. 여러 표기는 줄바꿈으로 모두 등록합니다. 데이터를 불러올 때 자동 정산합니다.
